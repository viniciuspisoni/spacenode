## Como publicar

1. Abrir o mp4 no Instagram, escolher a trilha na biblioteca do app (os arquivos saem sem áudio de propósito — Reels com áudio da biblioteca distribuem melhor).
2. Colar a legenda de `caption.txt` (o gancho é a 1ª linha, o que aparece antes do "mais").
3. Capa: usar um frame do render, sem texto.
4. Para tráfego pago: usar a versão `-ad` quando existir e as três variações de copy do bloco "VERSÃO PAGA" da legenda.
