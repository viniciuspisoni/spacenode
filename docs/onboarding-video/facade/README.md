# Exemplo de configuração de uma fachada

Capturado em 13/10/2026 em `https://spacenode.app/app/generate`, com a imagem pública demonstrativa da própria SpaceNode (`public/demo-sketch.jpg`). São recortes da interface em funcionamento, sem identidade ou saldo da conta. A estimativa de gerações disponível na conta foi ocultada no recorte `ready.jpg`; o custo da operação e o botão foram preservados.

A imagem foi carregada e configurada como Exterior / Residencial / Fachada Residencial, Golden Hour, materiais originais e Vega 2K (20 Nodes observados). A orientação preenchida foi: “Apresente esta fachada com luz suave de fim de tarde. Mantenha concreto, vidro, aberturas e enquadramento do modelo.”

O botão Gerar render ficou habilitado. Nenhuma geração foi iniciada para gravar este vídeo. Não é uma promessa de resultado nem um caso de cliente.
